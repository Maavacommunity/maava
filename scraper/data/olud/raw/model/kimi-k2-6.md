### Frequently asked questions

#### What is Kimi K2.6?
Kimi K2.6 is an AI language model from Moonshot AI. It is open-weight: you can download it and run it on your own hardware, for free. It scores 45.1 on the Artificial Analysis intelligence index.

#### Is Kimi K2.6 free?
The weights are free and open — you can self-host Kimi K2.6 and pay nothing per token. If you prefer a hosted API, list prices are $0.95 per million input tokens and $4 per million output tokens.

#### What is Kimi K2.6 good at?
Independent benchmarks from Artificial Analysis give it GPQA 91.1%, Humanity's Last Exam 37.5%, Long Context Reasoning 76.7%, SciCode 53.5%, IFBench 76%, τ²-Bench 95.9%, τ-Bench Banking 23.3%, Terminal-Bench 65.9%, Terminal-Bench Hard 43.9%. It is particularly used for code generation.

#### Can I self-host Kimi K2.6?
Yes. Kimi K2.6 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
