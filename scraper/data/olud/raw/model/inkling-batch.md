### Frequently asked questions

#### What is Inkling (batch)?
Inkling (batch) is an AI language model from Thinkingmachines. It is open-weight: you can download it and run it on your own hardware, for free. It scores 42.3 on the Artificial Analysis intelligence index.

#### Is Inkling (batch) free?
The weights are free and open — you can self-host Inkling (batch) and pay nothing per token. If you prefer a hosted API, list prices are $1 per million input tokens and $4.05 per million output tokens.

#### What is Inkling (batch) good at?
Independent benchmarks from Artificial Analysis give it GPQA 87.2%, Humanity's Last Exam 31.9%, Long Context Reasoning 73.3%, SciCode 46.1%, τ-Bench Banking 29.1%, Terminal-Bench 55.1%. It is particularly used for code generation.

#### How fast is Inkling (batch)?
It generates about 57.2 tokens per second, with a median 2.55s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Inkling (batch)?
Yes. Inkling (batch) has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
