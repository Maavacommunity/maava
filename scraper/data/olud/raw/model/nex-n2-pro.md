### Frequently asked questions

#### What is Nex-N2-Pro?
Nex-N2-Pro is an AI language model from Nex agi. It is open-weight: you can download it and run it on your own hardware, for free. It scores 41.7 on the Artificial Analysis intelligence index.

#### Is Nex-N2-Pro free?
The weights are free and open — you can self-host Nex-N2-Pro and pay nothing per token. If you prefer a hosted API, list prices are $0.25 per million input tokens and $1 per million output tokens.

#### What is Nex-N2-Pro good at?
Independent benchmarks from Artificial Analysis give it GPQA 89.2%, Humanity's Last Exam 33.7%, Long Context Reasoning 76.3%, SciCode 41.8%, IFBench 66.2%, τ²-Bench 81.6%, τ-Bench Banking 17.5%, Terminal-Bench 67.8%. It is particularly used for code generation.

#### How fast is Nex-N2-Pro?
It generates about 138.7 tokens per second, with a median 0.88s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Nex-N2-Pro?
Yes. Nex-N2-Pro has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
