### Frequently asked questions

#### What is R1?
R1 is an AI language model from DeepSeek. It is open-weight: you can download it and run it on your own hardware, for free. It scores 18.6 on the Artificial Analysis intelligence index.

#### Is R1 free?
The weights are free and open — you can self-host R1 and pay nothing per token. If you prefer a hosted API, list prices are $0.7 per million input tokens and $2.5 per million output tokens.

#### What is R1 good at?
Independent benchmarks from Artificial Analysis give it GPQA 70.8%, MMLU-Pro 84.4%, Humanity's Last Exam 8.5%, Long Context Reasoning 56%, LiveCodeBench 61.7%, SciCode 35.7%, MATH-500 96.6%, AIME 68.3%, AIME 2025 68%, IFBench 39%, τ²-Bench 11.4%, τ-Bench Banking 6.4%, Terminal-Bench 19.1%, Terminal-Bench Hard 6.1%. It is particularly used for code generation.

#### Can I self-host R1?
Yes. R1 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
