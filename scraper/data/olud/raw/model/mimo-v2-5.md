### Frequently asked questions

#### What is MiMo-V2.5?
MiMo-V2.5 is an AI language model from Xiaomi. It is open-weight: you can download it and run it on your own hardware, for free. It scores 38 on the Artificial Analysis intelligence index.

#### Is MiMo-V2.5 free?
The weights are free and open — you can self-host MiMo-V2.5 and pay nothing per token. If you prefer a hosted API, list prices are $0.14 per million input tokens and $0.28 per million output tokens.

#### What is MiMo-V2.5 good at?
Independent benchmarks from Artificial Analysis give it GPQA 84.9%, Humanity's Last Exam 27.2%, Long Context Reasoning 68.3%, SciCode 43.1%, IFBench 67.1%, τ²-Bench 90.6%, τ-Bench Banking 8.7%, Terminal-Bench 63.7%, Terminal-Bench Hard 41.7%. It is particularly used for code generation.

#### How fast is MiMo-V2.5?
It generates about 67.2 tokens per second, with a median 2.01s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host MiMo-V2.5?
Yes. MiMo-V2.5 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
