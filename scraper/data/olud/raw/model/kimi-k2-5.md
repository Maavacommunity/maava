### Frequently asked questions

#### What is Kimi K2.5?
Kimi K2.5 is an AI language model from Moonshot AI. It is open-weight: you can download it and run it on your own hardware, for free. It scores 36 on the Artificial Analysis intelligence index.

#### Is Kimi K2.5 free?
The weights are free and open — you can self-host Kimi K2.5 and pay nothing per token. If you prefer a hosted API, list prices are $0.6 per million input tokens and $3 per million output tokens.

#### What is Kimi K2.5 good at?
Independent benchmarks from Artificial Analysis give it GPQA 87.9%, Humanity's Last Exam 30.7%, Long Context Reasoning 73%, SciCode 49%, IFBench 70.2%, τ²-Bench 95.9%, τ-Bench Banking 14.2%, Terminal-Bench 45.7%, Terminal-Bench Hard 34.8%. It is particularly used for code generation.

#### Can I self-host Kimi K2.5?
Yes. Kimi K2.5 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
