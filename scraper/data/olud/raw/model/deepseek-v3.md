### Frequently asked questions

#### What is DeepSeek V3?
DeepSeek V3 is an AI language model from DeepSeek. It is open-weight: you can download it and run it on your own hardware, for free. It scores 14.2 on the Artificial Analysis intelligence index.

#### Is DeepSeek V3 free?
The weights are free and open — you can self-host DeepSeek V3 and pay nothing per token. If you prefer a hosted API, list prices are $0.26 per million input tokens and $1.03 per million output tokens.

#### What is DeepSeek V3 good at?
Independent benchmarks from Artificial Analysis give it GPQA 55.7%, MMLU-Pro 75.2%, Humanity's Last Exam 2.9%, Long Context Reasoning 31.7%, LiveCodeBench 35.9%, SciCode 35.4%, MATH-500 88.7%, AIME 25.3%, AIME 2025 26%, IFBench 34.8%, τ²-Bench 22.8%, τ-Bench Banking 4.7%, Terminal-Bench 16.9%, Terminal-Bench Hard 6.8%. It is particularly used for code generation.

#### Can I self-host DeepSeek V3?
Yes. DeepSeek V3 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
