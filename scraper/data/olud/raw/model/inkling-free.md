### Frequently asked questions

#### What is Inkling (free)?
Inkling (free) is an AI language model from Thinkingmachines. It is open-weight: you can download it and run it on your own hardware, for free. It scores 42.3 on the Artificial Analysis intelligence index.

#### Is Inkling (free) free?
The weights are free and open — you can self-host Inkling (free) and pay nothing per token. If you prefer a hosted API, list prices are Free per million input tokens and Free per million output tokens.

#### What is Inkling (free) good at?
Independent benchmarks from Artificial Analysis give it GPQA 87.2%, Humanity's Last Exam 31.9%, Long Context Reasoning 73.3%, SciCode 46.1%, τ-Bench Banking 29.1%, Terminal-Bench 55.1%. It is particularly used for code generation.

#### How fast is Inkling (free)?
It generates about 57.2 tokens per second, with a median 2.55s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Inkling (free)?
Yes. Inkling (free) has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
