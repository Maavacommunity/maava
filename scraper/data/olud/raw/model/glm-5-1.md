### Frequently asked questions

#### What is GLM 5.1?
GLM 5.1 is an AI language model from Z.AI. It is open-weight: you can download it and run it on your own hardware, for free. It scores 41 on the Artificial Analysis intelligence index.

#### Is GLM 5.1 free?
The weights are free and open — you can self-host GLM 5.1 and pay nothing per token. If you prefer a hosted API, list prices are $1.26 per million input tokens and $3.96 per million output tokens.

#### What is GLM 5.1 good at?
Independent benchmarks from Artificial Analysis give it GPQA 86.8%, Humanity's Last Exam 30.1%, Long Context Reasoning 68%, SciCode 43.8%, IFBench 76.3%, τ²-Bench 97.7%, τ-Bench Banking 13.6%, Terminal-Bench 61.8%, Terminal-Bench Hard 43.2%. It is particularly used for code generation.

#### Can I self-host GLM 5.1?
Yes. GLM 5.1 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
