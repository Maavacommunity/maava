### Frequently asked questions

#### What is GLM 5.2?
GLM 5.2 is an AI language model from Z.AI. It is open-weight: you can download it and run it on your own hardware, for free. It scores 52.6 on the Artificial Analysis intelligence index.

#### Is GLM 5.2 free?
The weights are free and open — you can self-host GLM 5.2 and pay nothing per token. If you prefer a hosted API, list prices are $1.19 per million input tokens and $3.74 per million output tokens.

#### What is GLM 5.2 good at?
Independent benchmarks from Artificial Analysis give it GPQA 89.5%, Humanity's Last Exam 41.1%, Long Context Reasoning 76.7%, SciCode 50.5%, IFBench 73.3%, τ²-Bench 99.1%, τ-Bench Banking 34.6%, Terminal-Bench 77.9%, Terminal-Bench Hard 50.8%. It is particularly used for code generation.

#### How fast is GLM 5.2?
It generates about 68.8 tokens per second, with a median 1.12s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host GLM 5.2?
Yes. GLM 5.2 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
