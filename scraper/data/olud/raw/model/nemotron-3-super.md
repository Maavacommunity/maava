### Frequently asked questions

#### What is Nemotron 3 Super?
Nemotron 3 Super is an AI language model from NVIDIA. It is open-weight: you can download it and run it on your own hardware, for free. It scores 25.7 on the Artificial Analysis intelligence index.

#### Is Nemotron 3 Super free?
The weights are free and open — you can self-host Nemotron 3 Super and pay nothing per token. If you prefer a hosted API, list prices are $0.08 per million input tokens and $0.4 per million output tokens.

#### What is Nemotron 3 Super good at?
Independent benchmarks from Artificial Analysis give it GPQA 80%, Humanity's Last Exam 20.8%, Long Context Reasoning 60.3%, SciCode 36%, IFBench 71.5%, τ²-Bench 67.8%, τ-Bench Banking 10.3%, Terminal-Bench 38.6%, Terminal-Bench Hard 28.8%. It is particularly used for code generation.

#### How fast is Nemotron 3 Super?
It generates about 144.2 tokens per second, with a median 1.11s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Nemotron 3 Super?
Yes. Nemotron 3 Super has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
