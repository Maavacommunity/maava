### Frequently asked questions

#### What is Kimi K2.7 Code?
Kimi K2.7 Code is an AI language model from Moonshot AI. It is open-weight: you can download it and run it on your own hardware, for free. It scores 43 on the Artificial Analysis intelligence index.

#### Is Kimi K2.7 Code free?
The weights are free and open — you can self-host Kimi K2.7 Code and pay nothing per token. If you prefer a hosted API, list prices are $0.66 per million input tokens and $3.4 per million output tokens.

#### What is Kimi K2.7 Code good at?
Independent benchmarks from Artificial Analysis give it GPQA 89.6%, Humanity's Last Exam 35%, Long Context Reasoning 75%, SciCode 47.5%, IFBench 63.1%, τ²-Bench 90.1%, τ-Bench Banking 20.2%, Terminal-Bench 67.4%, Terminal-Bench Hard 44.7%. It is particularly used for code generation.

#### How fast is Kimi K2.7 Code?
It generates about 39.5 tokens per second, with a median 1.28s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Kimi K2.7 Code?
Yes. Kimi K2.7 Code has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
