### Frequently asked questions

#### What is Nemotron 3.5 Lightning?
Nemotron 3.5 Lightning is an AI language model from NVIDIA. It is open-weight: you can download it and run it on your own hardware, for free. It scores 23.6 on the Artificial Analysis intelligence index.

#### Is Nemotron 3.5 Lightning free?
The weights are free and open — you can self-host Nemotron 3.5 Lightning and pay nothing per token. If you prefer a hosted API, list prices are $0.08 per million input tokens and $0.2 per million output tokens.

#### What is Nemotron 3.5 Lightning good at?
Independent benchmarks from Artificial Analysis give it GPQA 74.3%, Humanity's Last Exam 10.6%, Long Context Reasoning 55.3%, SciCode 31.6%, τ-Bench Banking 8.9%, Terminal-Bench 24.3%. It is particularly used for code generation.

#### How fast is Nemotron 3.5 Lightning?
It generates about 298.9 tokens per second, with a median 0.79s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Nemotron 3.5 Lightning?
Yes. Nemotron 3.5 Lightning has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
