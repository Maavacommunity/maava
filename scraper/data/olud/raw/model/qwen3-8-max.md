### Frequently asked questions

#### What is Qwen3.8 Max?
Qwen3.8 Max is an AI language model from Alibaba. It is open-weight: you can download it and run it on your own hardware, for free. It scores 58.1 on the Artificial Analysis intelligence index.

#### Is Qwen3.8 Max free?
The weights are free and open — you can self-host Qwen3.8 Max and pay nothing per token. If you prefer a hosted API, list prices are $2 per million input tokens and $6 per million output tokens.

#### What is Qwen3.8 Max good at?
Independent benchmarks from Artificial Analysis give it GPQA 92.7%, Humanity's Last Exam 43%, Long Context Reasoning 74.3%, SciCode 52.9%, τ-Bench Banking 51.3%, Terminal-Bench 81.3%. It is particularly used for code generation.

#### How fast is Qwen3.8 Max?
It generates about 25.7 tokens per second, with a median 1.76s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Qwen3.8 Max?
Yes. Qwen3.8 Max has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
