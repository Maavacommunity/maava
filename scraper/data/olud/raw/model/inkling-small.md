### Frequently asked questions

#### What is Inkling Small?
Inkling Small is an AI language model from Thinkingmachines. It is open-weight: you can download it and run it on your own hardware, for free. It scores 41.2 on the Artificial Analysis intelligence index.

#### Is Inkling Small free?
The weights are free and open — you can self-host Inkling Small and pay nothing per token. If you prefer a hosted API, list prices are $0.45 per million input tokens and $1.2 per million output tokens.

#### What is Inkling Small good at?
Independent benchmarks from Artificial Analysis give it GPQA 89.5%, Humanity's Last Exam 33.3%, Long Context Reasoning 69.3%, SciCode 48.7%, τ-Bench Banking 18.8%, Terminal-Bench 55.1%. It is particularly used for code generation.

#### How fast is Inkling Small?
It generates about 61.4 tokens per second, with a median 2.19s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Inkling Small?
Yes. Inkling Small has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
