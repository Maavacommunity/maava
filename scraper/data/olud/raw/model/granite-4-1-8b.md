### Frequently asked questions

#### What is Granite 4.1 8B?
Granite 4.1 8B is an AI language model from IBM. It is open-weight: you can download it and run it on your own hardware, for free. It scores 6.4 on the Artificial Analysis intelligence index.

#### Is Granite 4.1 8B free?
The weights are free and open — you can self-host Granite 4.1 8B and pay nothing per token. If you prefer a hosted API, list prices are $0.05 per million input tokens and $0.1 per million output tokens.

#### What is Granite 4.1 8B good at?
Independent benchmarks from Artificial Analysis give it GPQA 43.3%, Humanity's Last Exam 3.8%, Long Context Reasoning 11.3%, SciCode 21.8%, IFBench 38.6%, τ²-Bench 27.8%, Terminal-Bench 3.4%, Terminal-Bench Hard 0%. It is particularly used for code generation.

#### How fast is Granite 4.1 8B?
It generates about 126.2 tokens per second, with a median 0.45s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Granite 4.1 8B?
Yes. Granite 4.1 8B has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
