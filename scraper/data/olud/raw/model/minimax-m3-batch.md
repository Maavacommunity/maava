### Frequently asked questions

#### What is MiniMax M3 (batch)?
MiniMax M3 (batch) is an AI language model from MiniMax. It is open-weight: you can download it and run it on your own hardware, for free. It scores 45.4 on the Artificial Analysis intelligence index.

#### Is MiniMax M3 (batch) free?
The weights are free and open — you can self-host MiniMax M3 (batch) and pay nothing per token. If you prefer a hosted API, list prices are $0.3 per million input tokens and $1.2 per million output tokens.

#### What is MiniMax M3 (batch) good at?
Independent benchmarks from Artificial Analysis give it GPQA 92.9%, Humanity's Last Exam 39%, Long Context Reasoning 80.3%, SciCode 45.4%, IFBench 82.9%, τ²-Bench 88.9%, τ-Bench Banking 15.3%, Terminal-Bench 65.2%, Terminal-Bench Hard 42.4%. It is particularly used for code generation.

#### How fast is MiniMax M3 (batch)?
It generates about 106.8 tokens per second, with a median 0.94s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host MiniMax M3 (batch)?
Yes. MiniMax M3 (batch) has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
