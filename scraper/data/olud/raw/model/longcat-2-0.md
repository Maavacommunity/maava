### Frequently asked questions

#### What is LongCat 2.0?
LongCat 2.0 is an AI language model from Meituan. It is open-weight: you can download it and run it on your own hardware, for free. It scores 34 on the Artificial Analysis intelligence index.

#### Is LongCat 2.0 free?
The weights are free and open — you can self-host LongCat 2.0 and pay nothing per token. If you prefer a hosted API, list prices are $0.3 per million input tokens and $1.2 per million output tokens.

#### What is LongCat 2.0 good at?
Independent benchmarks from Artificial Analysis give it GPQA 78%, Humanity's Last Exam 33.7%, Long Context Reasoning 62.7%, SciCode 35.4%, τ-Bench Banking 13.2%, Terminal-Bench 50.2%. It is particularly used for code generation.

#### How fast is LongCat 2.0?
It generates about 41.6 tokens per second, with a median 2.07s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host LongCat 2.0?
Yes. LongCat 2.0 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
