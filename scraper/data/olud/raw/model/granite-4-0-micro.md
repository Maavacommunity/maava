### Frequently asked questions

#### What is Granite 4.0 Micro?
Granite 4.0 Micro is an AI language model from IBM. It is open-weight: you can download it and run it on your own hardware, for free. It scores 2 on the Artificial Analysis intelligence index.

#### Is Granite 4.0 Micro free?
The weights are free and open — you can self-host Granite 4.0 Micro and pay nothing per token. If you prefer a hosted API, list prices are $0.02 per million input tokens and $0.11 per million output tokens.

#### What is Granite 4.0 Micro good at?
Independent benchmarks from Artificial Analysis give it GPQA 33.6%, MMLU-Pro 44.7%, Humanity's Last Exam 5%, Long Context Reasoning 5.7%, LiveCodeBench 18%, SciCode 11.9%, AIME 2025 6%, IFBench 24.8%, τ²-Bench 12.6%, Terminal-Bench Hard 1.5%. It is particularly used for mathematical reasoning.

#### Can I self-host Granite 4.0 Micro?
Yes. Granite 4.0 Micro has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
