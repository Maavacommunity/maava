### Frequently asked questions

#### What is Nemotron 3 Ultra?
Nemotron 3 Ultra is an AI language model from NVIDIA. It is open-weight: you can download it and run it on your own hardware, for free. It scores 38.3 on the Artificial Analysis intelligence index.

#### Is Nemotron 3 Ultra free?
The weights are free and open — you can self-host Nemotron 3 Ultra and pay nothing per token. If you prefer a hosted API, list prices are $0.5 per million input tokens and $2.2 per million output tokens.

#### What is Nemotron 3 Ultra good at?
Independent benchmarks from Artificial Analysis give it GPQA 86.7%, Humanity's Last Exam 28.4%, Long Context Reasoning 71%, SciCode 39.9%, IFBench 81.4%, τ²-Bench 83.3%, τ-Bench Banking 14.2%, Terminal-Bench 53.9%, Terminal-Bench Hard 36.4%. It is particularly used for code generation.

#### How fast is Nemotron 3 Ultra?
It generates about 172.5 tokens per second, with a median 1.2s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Nemotron 3 Ultra?
Yes. Nemotron 3 Ultra has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
