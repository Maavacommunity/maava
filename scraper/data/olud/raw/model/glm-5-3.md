### Frequently asked questions

#### What is GLM 5.3?
GLM 5.3 is an AI language model from Z.AI. It is open-weight: you can download it and run it on your own hardware, for free. It scores 59.5 on the Artificial Analysis intelligence index.

#### Is GLM 5.3 free?
The weights are free and open — you can self-host GLM 5.3 and pay nothing per token. If you prefer a hosted API, list prices are $1.4 per million input tokens and $4.4 per million output tokens.

#### What is GLM 5.3 good at?
Independent benchmarks from Artificial Analysis give it GPQA 91.7%, Humanity's Last Exam 42.3%, Long Context Reasoning 76.3%, SciCode 56.5%, τ-Bench Banking 50.3%, Terminal-Bench 83.9%. It is particularly used for code generation.

#### How fast is GLM 5.3?
It generates about 65.9 tokens per second, with a median 1.54s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host GLM 5.3?
Yes. GLM 5.3 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
