### Frequently asked questions

#### What is Trinity Large Thinking?
Trinity Large Thinking is an AI language model from Arcee ai. It is open-weight: you can download it and run it on your own hardware, for free. It scores 18.7 on the Artificial Analysis intelligence index.

#### Is Trinity Large Thinking free?
The weights are free and open — you can self-host Trinity Large Thinking and pay nothing per token. If you prefer a hosted API, list prices are $0.22 per million input tokens and $0.85 per million output tokens.

#### What is Trinity Large Thinking good at?
Independent benchmarks from Artificial Analysis give it GPQA 75.2%, Humanity's Last Exam 15.8%, Long Context Reasoning 38.3%, SciCode 36.1%, IFBench 56.3%, τ²-Bench 90.1%, τ-Bench Banking 5.8%, Terminal-Bench 20.6%, Terminal-Bench Hard 22.7%. It is particularly used for code generation.

#### How fast is Trinity Large Thinking?
It generates about 205.2 tokens per second, with a median 0.72s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Trinity Large Thinking?
Yes. Trinity Large Thinking has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
