### Frequently asked questions

#### What is Qwen3 Coder Next?
Qwen3 Coder Next is an AI language model from Alibaba. It is open-weight: you can download it and run it on your own hardware, for free. It scores 21.3 on the Artificial Analysis intelligence index.

#### Is Qwen3 Coder Next free?
The weights are free and open — you can self-host Qwen3 Coder Next and pay nothing per token. If you prefer a hosted API, list prices are $0.12 per million input tokens and $0.8 per million output tokens.

#### What is Qwen3 Coder Next good at?
Independent benchmarks from Artificial Analysis give it GPQA 73.7%, Humanity's Last Exam 10.1%, Long Context Reasoning 42.3%, SciCode 32.3%, IFBench 35.2%, τ²-Bench 79.5%, τ-Bench Banking 5.4%, Terminal-Bench 38.2%, Terminal-Bench Hard 18.2%. It is particularly used for code generation.

#### How fast is Qwen3 Coder Next?
It generates about 124.9 tokens per second, with a median 0.93s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Qwen3 Coder Next?
Yes. Qwen3 Coder Next has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
