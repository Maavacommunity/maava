### Frequently asked questions

#### What is GLM 4.7?
GLM 4.7 is an AI language model from Z.AI. It is open-weight: you can download it and run it on your own hardware, for free. It scores 34.5 on the Artificial Analysis intelligence index.

#### Is GLM 4.7 free?
The weights are free and open — you can self-host GLM 4.7 and pay nothing per token. If you prefer a hosted API, list prices are $0.4 per million input tokens and $1.75 per million output tokens.

#### What is GLM 4.7 good at?
Independent benchmarks from Artificial Analysis give it GPQA 85.9%, MMLU-Pro 85.6%, Humanity's Last Exam 27.4%, Long Context Reasoning 68%, LiveCodeBench 89.4%, SciCode 45.1%, AIME 2025 95%, IFBench 67.9%, τ²-Bench 95.9%, τ-Bench Banking 12.2%, Terminal-Bench 45.3%, Terminal-Bench Hard 31.8%. It is particularly used for code generation.

#### Can I self-host GLM 4.7?
Yes. GLM 4.7 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
