### Frequently asked questions

#### What is Hy3?
Hy3 is an AI language model from Tencent. It is open-weight: you can download it and run it on your own hardware, for free. It scores 42.2 on the Artificial Analysis intelligence index.

#### Is Hy3 free?
The weights are free and open — you can self-host Hy3 and pay nothing per token. If you prefer a hosted API, list prices are $0.08 per million input tokens and $0.33 per million output tokens.

#### What is Hy3 good at?
Independent benchmarks from Artificial Analysis give it GPQA 89.7%, Humanity's Last Exam 33.5%, Long Context Reasoning 74.7%, SciCode 47.6%, τ-Bench Banking 22.9%, Terminal-Bench 64.4%. It is particularly used for code generation.

#### How fast is Hy3?
It generates about 70.5 tokens per second, with a median 1.8s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Hy3?
Yes. Hy3 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
