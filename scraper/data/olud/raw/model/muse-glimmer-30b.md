### Frequently asked questions

#### What is Muse Glimmer 30B?
Muse Glimmer 30B is an AI language model from Meta. It is open-weight: you can download it and run it on your own hardware, for free. It scores 35.1 on the Artificial Analysis intelligence index.

#### Is Muse Glimmer 30B free?
The weights are free and open — you can self-host Muse Glimmer 30B and pay nothing per token. If you prefer a hosted API, list prices are $0.35 per million input tokens and $1.5 per million output tokens.

#### What is Muse Glimmer 30B good at?
Independent benchmarks from Artificial Analysis give it GPQA 83.5%, Humanity's Last Exam 22%, Long Context Reasoning 80%, SciCode 43.6%, τ-Bench Banking 23.5%, Terminal-Bench 51.7%. It is particularly used for code generation.

#### How fast is Muse Glimmer 30B?
It generates about 104.2 tokens per second, with a median 0.36s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Muse Glimmer 30B?
Yes. Muse Glimmer 30B has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
