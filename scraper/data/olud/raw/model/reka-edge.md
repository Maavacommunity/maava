### Frequently asked questions

#### What is Reka Edge?
Reka Edge is an AI language model from Rekaai. It is open-weight: you can download it and run it on your own hardware, for free.

#### Is Reka Edge free?
The weights are free and open — you can self-host Reka Edge and pay nothing per token. If you prefer a hosted API, list prices are $0.1 per million input tokens and $0.1 per million output tokens.

#### Can I self-host Reka Edge?
Yes. Reka Edge has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
