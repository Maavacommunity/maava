### Frequently asked questions

#### What is Qwen3 8B?
Qwen3 8B is an AI language model from Alibaba. It is open-weight: you can download it and run it on your own hardware, for free. It scores 8.3 on the Artificial Analysis intelligence index.

#### Is Qwen3 8B free?
The weights are free and open — you can self-host Qwen3 8B and pay nothing per token. If you prefer a hosted API, list prices are $0.12 per million input tokens and $0.45 per million output tokens.

#### What is Qwen3 8B good at?
Independent benchmarks from Artificial Analysis give it GPQA 58.9%, MMLU-Pro 74.3%, Humanity's Last Exam 3.9%, Long Context Reasoning 0%, LiveCodeBench 40.6%, SciCode 22.6%, MATH-500 90.4%, AIME 74.7%, AIME 2025 19%, IFBench 33.5%, τ²-Bench 27.8%, τ-Bench Banking 4.7%, Terminal-Bench 2.2%, Terminal-Bench Hard 2.3%. It is particularly used for code generation.

#### Can I self-host Qwen3 8B?
Yes. Qwen3 8B has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
