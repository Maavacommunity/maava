### Frequently asked questions

#### What is MiniMax M2.7?
MiniMax M2.7 is an AI language model from MiniMax. It is open-weight: you can download it and run it on your own hardware, for free. It scores 38.9 on the Artificial Analysis intelligence index.

#### Is MiniMax M2.7 free?
The weights are free and open — you can self-host MiniMax M2.7 and pay nothing per token. If you prefer a hosted API, list prices are $0.3 per million input tokens and $1.2 per million output tokens.

#### What is MiniMax M2.7 good at?
Independent benchmarks from Artificial Analysis give it GPQA 87.4%, Humanity's Last Exam 29.6%, Long Context Reasoning 75.3%, SciCode 47%, IFBench 75.7%, τ²-Bench 84.8%, τ-Bench Banking 9.9%, Terminal-Bench 55.4%, Terminal-Bench Hard 39.4%. It is particularly used for code generation.

#### Can I self-host MiniMax M2.7?
Yes. MiniMax M2.7 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
