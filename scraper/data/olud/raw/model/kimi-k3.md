### Frequently asked questions

#### What is Kimi K3?
Kimi K3 is an AI language model from Moonshot AI. It is open-weight: you can download it and run it on your own hardware, for free. It scores 59.7 on the Artificial Analysis intelligence index.

#### Is Kimi K3 free?
The weights are free and open — you can self-host Kimi K3 and pay nothing per token. If you prefer a hosted API, list prices are $3 per million input tokens and $15 per million output tokens.

#### What is Kimi K3 good at?
Independent benchmarks from Artificial Analysis give it GPQA 93.5%, Humanity's Last Exam 46.9%, Long Context Reasoning 82.7%, SciCode 58.7%, τ-Bench Banking 46%, Terminal-Bench 85%. It is particularly used for code generation.

#### How fast is Kimi K3?
It generates about 37.9 tokens per second, with a median 5.48s delay before the first token. Measured independently by Artificial Analysis.

#### Can I self-host Kimi K3?
Yes. Kimi K3 has open weights, so you can download it and run it on your own GPU or server with tools like Ollama, vLLM or llama.cpp — with no per-token cost.
