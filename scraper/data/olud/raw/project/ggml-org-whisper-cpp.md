In plain wordswhisper.cpp is a dependency-free C/C++ port of Whisper that transcribes speech on CPUs, phones and even Raspberry Pi, powering countless local dictation tools.

### From the README
Install

```
git clone https://github.com/ggml-org/whisper.cpp.git
```
- Plain C/C++ implementation without dependencies
- Apple Silicon first-class citizen - optimized via ARM NEON, Accelerate framework, Metal and Core ML
- AVX intrinsics support for x86 architectures
- VSX intrinsics support for POWER architectures
- Mixed F16 / F32 precision
- Integer quantization support
