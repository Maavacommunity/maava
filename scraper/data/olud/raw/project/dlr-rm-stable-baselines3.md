In plain wordsStable-Baselines3 provides carefully tested PyTorch implementations of the main RL algorithms — PPO, SAC, TD3 — with sane defaults.

Install

```
pip install 'stable-baselines3[extra]'
```
- newer algorithms are regularly added to the SB3 Contrib repository
- faster variants are developed in the SBX (SB3 + Jax) repository
- the training framework for SB3, the RL Zoo, has an active roadmap
