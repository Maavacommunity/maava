In plain wordsTabby is a self-hosted AI coding assistant that provides completions across editors without sending code to a third party, with a team server you run yourself.

### From the README
Install

```
docker run -it \
--gpus all -p 8080:8080 -v $HOME/.tabby:/data \
tabbyml/tabby \
```
- Self-contained, with no need for a DBMS or cloud service.
- OpenAPI interface, easy to integrate with existing infrastructure (e.g Cloud IDE).
- Supports consumer-grade GPUs.
