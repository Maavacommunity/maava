Install

```
pip install "skyvern[all]"
```
- VITEAPIBASEURL (e.g. http://localhost:8000/api/v1) — points the UI at your Skyvern API
- VITESKYVERNAPIKEY — the API key if your API requires one
- VITEWSSBASEURL — WebSocket endpoint (inferred from VITEAPIBASEURL if unset)
- VITEARTIFACTAPIBASEURL — base URL for artifact downloads
- VITEBROWSERSTREAMINGMODE — browser viewport streaming mode
