📄 About

PyTorch implementations of various Deep Reinforcement Learning (DRL) algorithms for both single agent and multi-agent.

pytorch-DRL has 617 stars on GitHub. It has been forked 108 times. pytorch-DRL is written mainly in Python. It has been in active development since 2017. pytorch-DRL is available under the MIT license. Its main topics are a2c, acktr, actor-critic, advantage-actor-critic.
