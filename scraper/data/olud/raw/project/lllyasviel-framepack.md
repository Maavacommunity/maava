In plain wordsFramePack is a next-frame prediction approach that generates long videos progressively with low, constant VRAM use, making video generation practical on consumer GPUs.

### From the README
- Nvidia GPU in RTX 30XX, 40XX, 50XX series that supports fp16 and bf16. The GTX 10XX/20XX are not tested.
- Linux or Windows operating system.
- At least 6GB GPU memory.
