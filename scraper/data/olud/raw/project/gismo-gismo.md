📄 About

G+Smo (pronounced gismo or gizmo) is a C++ library for isogeometric analysis (IGA). Geometry plus simulation modules aims at the seamless integration of Computer-aided Design (CAD) and Finite Element Analysis (FEA).

gismo has 427 stars on GitHub. It has been forked 99 times. gismo is written mainly in C++. It has been in active development since 2015. gismo is available under the MPL-2.0 license. Its main topics are b-splines, bezier, cad, cagd.
