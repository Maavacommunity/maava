In plain wordschat-ui is the open SvelteKit application powering HuggingChat: multi-model chat with web search, tools and multimodal input, ready to point at your own inference endpoints.

### From the README
Install

```
git clone https://github.com/huggingface/chat-ui
cd chat-ui
npm install
```
- PUBLICAPPNAME The name used as a title throughout the app.
- PUBLICAPPASSETS Is used to find logos & favicons in static/$PUBLICAPPASSETS, current options are chatui and huggingchat.
- PUBLICAPPDATASHARING Can be set to 1 to add a toggle in the user settings that lets your users opt-in to data sharing with models creator.
