### From the README
Install

```
docker run -d -p 8080:80 doocs/md:latest
```
- 支持标准 Markdown 语法及数学公式（KaTeX）
- 支持 Mermaid 图表、PlantUML、GFM 警告块
- 支持 Ruby 注音扩展，格式兼容 [文字]{注音} 与 [文字]^(注音)
- 代码块提供多种高亮主题，可自定义主题色与 CSS 样式
- 内置本地草稿管理，支持内容自动保存
- 登录账户后可同步编辑器偏好（云同步说明）
