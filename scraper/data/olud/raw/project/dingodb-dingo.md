📄 About

A multi-modal vector database that supports upserts and vector queries using unified SQL (MySQL-Compatible) on structured and unstructured data, while meeting the requirements of high concurrency and ultra-low latency.

dingo has 1.7k stars on GitHub. It has been forked 264 times. dingo is written mainly in Java. It has been in active development since 2021. dingo is available under the Apache-2.0 license. Its main topics are embedding-search, embedding-store, hybrid-search, key-value-distributed-store.
