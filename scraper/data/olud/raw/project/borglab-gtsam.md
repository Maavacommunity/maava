📄 About

GTSAM is a library of C++ classes that implement smoothing and mapping (SAM) in robotics and vision, using factor graphs and Bayes networks as the underlying computing paradigm rather than sparse matrices.

gtsam has 3.6k stars on GitHub. It has been forked 963 times. gtsam is written mainly in Jupyter Notebook. It has been in active development since 2017. Its main topics are estimation, perception, robotics, sensorfusion.
