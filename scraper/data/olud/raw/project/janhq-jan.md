In plain wordsJan is a fully open-source desktop assistant that wraps local models in a clean ChatGPT-style UI, with a built-in model hub and an optional local API server.

### From the README
Install

```
git clone https://github.com/janhq/jan
cd jan
make dev
```
- Local AI Models: Download and run LLMs (Llama, Gemma, Qwen, GPT-oss etc.) from HuggingFace
- Cloud Integration: Connect to GPT models via OpenAI, Claude models via Anthropic, Mistral, Groq, MiniMax, and others
- Custom Assistants: Create specialized AI assistants for your tasks
