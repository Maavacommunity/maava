In plain wordsCreate and manage workflows, generate media, and edit projects using natural language in ComfyUI with various AI models (Claude Code required)

✓ Claimed by its maintainer

What it doesLets an AI agent drive your ComfyUI over MCP — build and run workflows, generate images/video/audio among other things

Who it is forPeople running ComfyUI (locally or on RunPod) who want Claude or any MCP client operating it — from chat, or CLI

What it does not doNot a hosted API and not a diffusion engine — it controls a ComfyUI you already have; you bring the install, the GPU, and the models
