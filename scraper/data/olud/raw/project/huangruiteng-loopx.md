In plain wordsLoopX is a lightweight, local-first state kernel for long-running AI agent work: durable goals, executable todos, evidence logs, quota-aware auto-wake and verifiable handoffs, agnostic of the agent runtime — Codex, Claude Code, Cursor or your own.

What it doesKeeps long-running AI agent work governed, resumable, and auditable across tools, sessions, and machines.

Who it is forDevelopers and teams running AI agents that must survive long tasks, handoffs, review gates, and failures.

What it does not doNot an agent runtime, model provider, or hosted automation service. LoopX governs state, authority, evidence, and continuation around the agents you already use
