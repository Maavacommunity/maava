### What is Letta?

Letta (formerly MemGPT) is a framework and server for building stateful agents with long-term memory that persists across sessions, with a visual agent editor.

### Why people choose Letta
- Persistent long-term agent memory
- Server with REST API and visual editor
- Model-agnostic and self-hostable

### FAQ

#### Is Letta free?
Letta is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run Letta locally?
Yes. Letta is designed to run on your own machine or server, keeping your data private.
