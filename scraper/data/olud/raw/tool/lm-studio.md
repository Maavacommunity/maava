### What is LM Studio?

LM Studio is a polished desktop app that lets you discover, download and chat with local models through a visual interface, with an optional OpenAI-compatible local server.

### Why people choose LM Studio
- The most polished GUI for exploring local models
- Built-in model browser with quantization details
- MCP-capable developer path and a local API server
