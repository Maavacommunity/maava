### What is Nexa SDK?

Nexa SDK runs text, vision, audio and image models locally across CPU, GPU and NPU backends, with a single unified API and OpenAI-compatible server.

### Why people choose Nexa SDK
- Runs on NPUs, not just CPU and GPU
- One API for text, vision and audio models
- OpenAI-compatible local server

### FAQ

#### Is Nexa SDK free?
Nexa SDK is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run Nexa SDK locally?
Yes. Nexa SDK is designed to run on your own machine or server, keeping your data private.
