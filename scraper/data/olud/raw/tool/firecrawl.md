### What is Firecrawl?

Firecrawl crawls websites and returns clean Markdown or structured data built for LLM consumption, handling JavaScript rendering and anti-bot pages.

### Why people choose Firecrawl
- Clean Markdown output built for LLMs
- Handles JavaScript-heavy sites
- Simple API, self-hostable

Firecrawl is free and open-source (AGPL-3.0 license), so you can use, self-host and modify it at no cost.

Yes. Firecrawl is designed to run on your own machine or server, keeping your data private.
