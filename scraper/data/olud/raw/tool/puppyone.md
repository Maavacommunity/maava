### What is Puppyone?

Puppyone is a local-first desktop editor for Markdown, documents, data files and media, with a built-in terminal that hosts coding agents such as Claude Code, Codex, Cursor and OpenCode; files stay on your machine unless you opt into its cloud.

### Why people choose Puppyone
- Edits and previews rich files: Markdown, DOCX, XLSX, PDF, media
- Built-in terminal with Claude Code, Codex, Cursor and OpenCode
- Local Git history; files stay local unless you choose its cloud
