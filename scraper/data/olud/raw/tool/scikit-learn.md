### What is scikit-learn?

scikit-learn is the reference library for everything that is not deep learning: regression, clustering, trees, preprocessing, evaluation.

### Why people choose scikit-learn
- A consistent API across every algorithm
- Documentation that teaches as much as it explains
- Rock-solid and used everywhere

### FAQ

#### Is scikit-learn free?
scikit-learn is free and open-source (BSD-3-Clause license), so you can use, self-host and modify it at no cost.

#### Can I run scikit-learn locally?
Yes. scikit-learn is designed to run on your own machine or server, keeping your data private.

#### What is the best alternative to scikit-learn?
Popular open-source alternatives include Dagster, TensorFlow, PyTorch. See the comparisons above to choose.
