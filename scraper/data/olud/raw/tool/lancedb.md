### What is LanceDB?

LanceDB is an open-source, embedded vector database built on the Lance columnar format, offering fast vector search with zero servers to manage.

### Why people choose LanceDB
- Embedded, no server to run
- Built on the fast Lance format
- Handles vectors plus metadata and files

### FAQ

#### Is LanceDB free?
LanceDB is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run LanceDB locally?
Yes. LanceDB is designed to run on your own machine or server, keeping your data private.
