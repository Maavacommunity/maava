### What is Crawl4AI?

Crawl4AI is a fast, fully open-source crawler that outputs LLM-friendly Markdown with smart extraction strategies, built to run entirely on your own machine.

### Why people choose Crawl4AI
- 100% free and local, no API key
- LLM-ready Markdown with extraction strategies
- Async and fast, browser-based crawling

### FAQ

#### Is Crawl4AI free?
Crawl4AI is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run Crawl4AI locally?
Yes. Crawl4AI is designed to run on your own machine or server, keeping your data private.
