### What is GPUStack?

GPUStack pools heterogeneous GPUs across machines into one cluster and schedules model workloads across them, with a web UI and OpenAI-compatible endpoints.

### Why people choose GPUStack
- Pools GPUs across many machines
- Mixes NVIDIA, Apple and AMD hardware
- Web UI with usage metrics

#### Is GPUStack free?
GPUStack is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run GPUStack locally?
Yes. GPUStack is designed to run on your own machine or server, keeping your data private.
