### What is Qdrant?

Qdrant is a high-performance vector database written in Rust, with rich filtering, payloads and a simple API for production semantic search and RAG.

### Why people choose Qdrant
- Very fast, written in Rust
- Rich payload filtering
- Simple API and easy self-hosting

### FAQ

#### Is Qdrant free?
Qdrant is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run Qdrant locally?
Yes. Qdrant is designed to run on your own machine or server, keeping your data private.

#### What is the best alternative to Qdrant?
Popular open-source alternatives include Weaviate, Milvus, Chroma. See the comparisons above to choose.
