### What is Weaviate?

Weaviate is an open-source vector database with built-in vectorization modules, hybrid search and a GraphQL API for AI-native applications.

### Why people choose Weaviate
- Built-in vectorization and reranker modules
- Hybrid (vector + keyword) search
- GraphQL and REST APIs

### FAQ

#### Is Weaviate free?
Weaviate is free and open-source (BSD-3-Clause license), so you can use, self-host and modify it at no cost.

#### Can I run Weaviate locally?
Yes. Weaviate is designed to run on your own machine or server, keeping your data private.
