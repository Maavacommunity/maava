### What is Open WebUI Pipelines?

Pipelines lets you inject arbitrary Python logic — RAG, filters, rate limits, monitoring — into any OpenAI-compatible chat interface without forking it.

### Why people choose Open WebUI Pipelines
- Custom Python logic on any OpenAI-compatible UI
- No fork needed to extend the interface
- Filters, RAG and monitoring hooks
