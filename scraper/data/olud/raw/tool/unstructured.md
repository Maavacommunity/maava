- For plain text files, HTML, XML, JSON and Emails that do not require any extra dependencies, you can run pip install unstructured
- To process other doc types, you can install the extras required for those documents, such as pip install "unstructured[docx,pptx]"

### What is Unstructured?

Unstructured extracts and normalizes content from PDFs, HTML, Word, emails and more into clean elements ready for embedding and RAG ingestion.

### Why people choose Unstructured
- One API for dozens of file formats
- Chunking strategies designed for RAG
- Widely adopted in the LLM data stack
