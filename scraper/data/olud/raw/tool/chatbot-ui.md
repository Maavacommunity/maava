### What is Chatbot UI?

Chatbot UI is a polished open-source chat interface supporting multiple providers, file uploads and per-user workspaces, backed by Supabase for auth and storage.

### Why people choose Chatbot UI
- Very familiar ChatGPT-style UX
- Files, folders and multi-workspace support
- Self-host with Supabase, bring any model key
