### What is HuggingChat UI?

chat-ui is the open SvelteKit application powering HuggingChat: multi-model chat with web search, tools and multimodal input, ready to point at your own inference endpoints.

### Why people choose HuggingChat UI
- Runs HuggingChat in production — proven at scale
- Web search and tool use built in
- Connects to TGI, vLLM or any OpenAI-compatible server

### FAQ

#### Is HuggingChat UI free?
HuggingChat UI is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run HuggingChat UI locally?
Yes. HuggingChat UI is designed to run on your own machine or server, keeping your data private.
