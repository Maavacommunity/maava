### What is AnythingLLM?

AnythingLLM is a document-and-agent app built around RAG: create workspaces, drop in files and chat against them with an embedded vector store, plus an agent mode.

### Why people choose AnythingLLM
- Purpose-built for document RAG with workspaces
- Embedded vector store, no extra infra
- Runs as a desktop app or in Docker
