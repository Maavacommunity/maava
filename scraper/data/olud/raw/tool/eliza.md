### What is Eliza?

elizaOS is a TypeScript framework for autonomous agents with personas, memory and connectors to Discord, X and Telegram — the framework behind many social AI agents.

### Why people choose Eliza
- Personas and long-term memory out of the box
- Native Discord, X and Telegram connectors
- Huge plugin ecosystem in TypeScript
