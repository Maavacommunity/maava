### What is Lobe Chat?

Lobe Chat is a modern, design-forward chat framework with a plugin and agent marketplace, voice support and one-click self-hosting.

### Why people choose Lobe Chat
- Beautiful, modern interface with theming
- Plugin and agent marketplace
- One-click deploy (Vercel, Docker)

### FAQ

#### Is Lobe Chat free?
Lobe Chat is free and open-source (MIT license), so you can use, self-host and modify it at no cost.

#### Can I run Lobe Chat locally?
Yes. Lobe Chat is designed to run on your own machine or server, keeping your data private.
