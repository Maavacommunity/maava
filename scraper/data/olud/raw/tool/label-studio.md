### What is Label Studio?

Label Studio is the open labelling platform for building the training data your model actually needs, with review workflows built in.

### Why people choose Label Studio
- Handles every data type in one tool
- Self-hosted: your data never leaves
- Model-assisted labelling to speed things up

### FAQ

#### Is Label Studio free?
Label Studio is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run Label Studio locally?
Yes. Label Studio is designed to run on your own machine or server, keeping your data private.
