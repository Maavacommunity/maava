### What is AI for Database?

AI for Database connects to an operational database and turns plain-language questions into queries, then into dashboards and scheduled workflows with authenticated webhook actions. It supports PostgreSQL, MySQL, MariaDB, Microsoft SQL Server, MongoDB and SQLite, with organization-scoped API keys. It is hosted only: the connection to your database is made from their infrastructure, not yours.

### Why people choose AI for Database
- Six database engines from one interface
- Scheduled workflows with authenticated webhooks
- Organization-scoped API keys
