### What is Hands-On Machine Learning?

Aurélien Géron's companion notebooks: scikit-learn for classical ML, then Keras and TensorFlow for deep learning — the reference practical ML book.

### Why people choose Hands-On Machine Learning
- The most widely used practical ML book
- Every chapter is a runnable notebook
- Covers classical ML properly, not just neural nets

### FAQ

#### Is Hands-On Machine Learning free?
Hands-On Machine Learning is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run Hands-On Machine Learning locally?
Yes. Hands-On Machine Learning is designed to run on your own machine or server, keeping your data private.
