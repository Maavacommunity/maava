### What is Void?

Void is a VS Code fork with AI built in: tab autocomplete, inline edits and agent mode, with your keys and full support for local models — no data middleman.

### Why people choose Void
- Familiar VS Code base with AI everywhere
- Direct provider connections — your keys, your data
- Agent and autocomplete work with local models
