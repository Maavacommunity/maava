### What is Chroma?

Chroma is a lightweight, developer-friendly embedding database that runs in-process, ideal for prototyping RAG apps with minimal setup.

### Why people choose Chroma
- Runs in-process, zero infrastructure to start
- Dead-simple Python API
- Great for prototypes and small apps

### FAQ

#### Is Chroma free?
Chroma is free and open-source (Apache-2.0 license), so you can use, self-host and modify it at no cost.

#### Can I run Chroma locally?
Yes. Chroma is designed to run on your own machine or server, keeping your data private.
