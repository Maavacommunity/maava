### About MCP servers
What is an MCP server?An MCP (Model Context Protocol) server exposes tools, data or actions to AI assistants like Claude through a standard protocol. Instead of building one integration per assistant, a vendor ships one MCP server and every MCP-compatible client can use it.

How is the MCP Score computed?MCP Score = activity (40 points: last push within 7/30/90/180 days) + popularity (30: logarithm of stars) + community (20: logarithm of forks) + maturity (10: repository age). It is deterministic, computed from public GitHub data at every refresh — no editorial weighting.

How are MCP servers detected?Three strict rules: a GitHub topic (mcp, mcp-server, model-context-protocol), "mcp" as a segment of the repository name, or the exact phrase "MCP server" / "Model Context Protocol" in the description. Ambiguous matches are excluded rather than guessed.
